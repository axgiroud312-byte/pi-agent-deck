# Agent Deck 0.9.2

将模型分工和最低思考强度设为强制执行策略，覆盖 Jev 选配、显式模型与别名、关闭自动选配、失败回退以及旧任务的后续启动。

| 模型 | 使用范围 | 允许强度 |
|---|---|---|
| GPT-5.6 Sol | 仅审查；审查也只能用它 | xhigh、max |
| GPT-6 Sol | 非审查 | high、xhigh、max |
| GPT-6 Luna | 非审查 | high、xhigh、max |
| GPT-6 Astra | 非审查 | low、medium、high、xhigh、max |

- 从原有 23 个选项收紧为 13 个：审查 2 个、非审查 11 个。组合及硬约束统一维护在 `model-profiles.json`。
- 内置 `reviewer` 与 `reportProfile: 审查` 的自定义角色使用审查策略。自动生成角色必须输出并保存类型；无效类型或模型设置拒绝保存，并可按原流程修正一次。
- 明确配置违反规则时，在创建 Session、任务或绑定实例名之前报错。继承值可调整到同一提供商的合规组合；无合规模型时提示修正，不自动切换账户。Jev 缺少密钥、超时或返回错误时也只用合规回退。
- GPT-6 Sol/Luna 的 Chat Completions 工具档位 `off` 低于最低 `high`，因此不进入候选；推理工具调用请配置 Responses。
- 主进程与独立 Runner 在启动前执行相同策略检查，并检查已保存决策与实际启动参数。自定义审查标记在首次选配后继续保留。
- 旧排队任务不合规时保存失败；旧终态任务不合规时拒绝继续并要求新建。自动补充停止策略错误重试，保留原有结果与待处理文字；仍可查看结果和停止任务。

升级后在已打开的 Pi 中执行 `/reload`。旧自定义审查角色没有 `reportProfile: 审查` 时，需要补上标记再新建任务；旧记录无法从任务文本可靠还原类型。已经运行的进程不会因升级自动终止或换模，请结束或停止后重新派遣。

保持 `Agent`、`SendMessage`、`TaskStop` 公开参数和无固定并发上限的设计。主 Agent 决定数量、角色、分工与验收；Jev 只选择合规的模型和思考强度。用户开关、Jev 设置和个人角色文件不被安装更新覆盖。

验证包含角色分池、明确覆盖与别名拒绝、低强度继承调整、模型能力映射、接口不兼容、关闭选配、错误回退、旧请求与续接、真实独立子进程、公开工具调用和 Pi 加载器。使用隔离目录与模拟接口，没有进行真实付费推理；组合用途是启发式建议，不是 Jev 质量评测。

完整规则见 [中文 README](../README.md#jev-负责模型与思考强度) 和 [Jev 组合说明](jev-routing.md)。0.9.1 等旧发布说明保留为历史记录。
