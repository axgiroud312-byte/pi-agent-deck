# Agent Deck 0.9.0

模型工具改为 Claude Code 风格的 `Agent`、`SendMessage`、`TaskStop`。创建、补充和停止各有独立接口；新工具不再接受旧式混合参数。Pi 的后台执行、中文面板、角色权限、工作区写入互斥和 Jev 选配继续保留。

- 创建时区分简短 `description`、完整 `prompt`、角色 `subagent_type` 和可选实例 `name`。公开 `agentId` 是稳定任务编号，`agentType` 是角色 ID；旧存储字段保持兼容。
- 同一主会话内的实例名称不区分大小写，创建检查与落盘串行保护。结束、重载后仍绑定原任务；其他主会话可独立复用。补充、停止不能跨主会话操作。
- `SendMessage` 的运行中消息持久化排队，当前轮结束后按顺序处理。摘要最多 200 字符，仅用于预览；完整正文不截断、不展开命令或文件引用。已结束或等答复的任务继续原 Session。
- `Agent.model` 可用完整标识或明确配置的 `modelAliases`。默认别名为空；不存在或无认证的模型在创建前报错。模型覆盖角色设置，Jev 选择尚未固定的部分；继续任务使用原实际模型和强度。
- 回执准确区分选配、排队、启动、恢复与终态。选配中不虚报最终模型。停止未确认仍明确显示，重复停止不改写已结束任务的状态。
- 面板以短标题为主，实例与角色分开显示。旧任务没有新字段时使用历史标题，仍支持查看、继续、停止。关闭派遣时同时停用 `Agent`、`SendMessage`，`TaskStop` 保持可用。

升级后在所有打开的 Pi 中执行 `/reload`。本版不重新开启已经关闭的派遣开关，不新增并发数量上限，不改用户角色或历史会话。无需新增依赖。

接口参考 Claude 官方文档，本版仍只支持后台任务；没有前台等待、实时消息注入、团队通信、工作树、远程执行或嵌套派遣。`run_in_background: false` 和不支持的参数会被拒绝。

验证命令为 `npm run check`、`npm test`。测试覆盖新工具实际执行、参数拒绝、重名并发、跨会话隔离、消息顺序、问题答复、取消、旧记录、配置保留、Jev 延迟返回以及 Pi 实际加载器。离线测试使用隔离目录、受控子进程与本地 HTTP 服务，不代表真实模型服务的在线成功率。部署报告另记本次真实服务验证结果。

回退前应结束新版任务并处理排队消息；旧版不能理解新版的结构化补充消息队列。代码、配置可从升级前备份恢复，历史任务保留供检查。
