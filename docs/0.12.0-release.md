# 0.12.0：明确委派、明确续接、只读查看进度

## 行为变化

主 Agent 负责需求澄清、任务分工、依赖安排和验收；子 Agent 在明确范围内自主执行。TUI 的主要用途是查看真实进度。

- 保留三个公开工具。`Agent({resume, prompt, description?})` 续接已结束任务，复用任务 ID、原模型和 Pi 子会话。新目标新建，返工和补查明确续接。
- SendMessage 只补充信息，空闲时暂存，不自动启动。公开 `delivery` 和 `reply_to` 已移除，旧参数返回迁移提示。
- 移除 agent_question 和阻塞问答流程。子 Agent 无法继续时提交阻塞结果，交回主 Agent 处理。
- 最终 agent_report 简化为交付状态、摘要、完成部分、证据、检查和剩余工作。提交后直接结束本轮，不再调用模型总结。
- 控制台 Enter 打开只读子会话，展示真实对话、工具调用/结果和执行中的公开输出；O 展开长工具输出，Esc 返回。移除 C/M/A 聊天和答复入口。打开页面不恢复进程、不切换主会话。
- 列表直接显示进程资源状态。结果页与通知共用失败原因、部分完成和验证说明。模型正常返回、检查报告与主 Agent 验收分别说明。

## 修复

- 结果保存失败仍关闭子进程并释放槽位，同时报告保存错误；失败的保存不阻断之后的写入。
- 模型错误原因不再被已有的部分输出掩盖。
- 新建子会话在启动另一个 Pi 进程前写入 Pi 生成的原生会话头，避免延迟落盘导致会话 ID 不一致。
- 明确续接会更新本轮要求和标题，清空本轮结果、错误和检查；上一轮结果保留为历史。
- 停止期间拒绝补充；结束边界上的补充留待明确 resume，不意外启动新执行。

## 保留

主 Pi 直接管理子 Pi RPC；每个主会话最多 8 个活跃任务；结束自动释放进程；旧会话和历史报告保留；无队列重放。Jev 只选模型和思考强度。Astra 禁用，审查仅 5.6 Sol 且最低 xhigh，6 Sol/Luna 最低 high。

## 升级

先等正在执行的任务结束，再更新并 `/reload`。不迁移运行中的旧进程。旧 `/agent-continue` 仅提示回到主会话明确续接。自定义角色原来的问题工具会被过滤；最终报告使用新格式。

## 验证范围

类型检查、完整回归、真实 Pi RPC 与可控本地模型、TUI 组件交互和打包检查。可控模型不调用付费服务，验证协议、状态和资源行为，不代表真实模型每次都能正确拆分和验收任务。实际结果见同目录 evidence/0.12.0/validation.md。
