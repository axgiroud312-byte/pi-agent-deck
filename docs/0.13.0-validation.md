## 审查与已知边界

- 独立只读审查覆盖数据合同、运行状态机、历史迁移、Git 提交边界和文档一致性；有效发现已修正并进入回归。
- `completed` 仅表示子运行正常结束，不表示业务要求已经满足。
- “一个正式文件实施者”是主模型和角色提示词的协作约定，不是写锁或文件系统沙箱。
- 扩展 provider 只有可序列化配置能桥接到隔离子 Pi；个人 provider 快照可能含认证信息，保留在 Pi 个人目录供 resume 使用，不进入仓库或 npm 包。
- 后台自动通知仅保证当前进程中仍活动的所属父会话；结果本身会持久化。
- 在线真实模型未执行，因此本记录不证明线上模型质量、身份、延迟或账户计费。
