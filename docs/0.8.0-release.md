# Agent Deck 0.8.0

主 Agent 继续负责数量、角色、分工与验收。新任务可由 Jev 在同一提供商的可用 Astra / Sol 组合中选择模型和思考强度；固定参数保留。

- 新增独立命令 `/agent-router on|off|status`、可取消的 `/agent-route-test [角色] 任务说明`。
- 任务编号先返回；后台选配，取消后迟到结果不启动子 Agent。继续原任务沿用已保存模型和强度。
- 移除全局及角色数量上限，旧 maxConcurrent 字段不再生效。同工作区写入互斥保留。
- 缺少密钥、接口故障、超时、非法结果与无候选均记录回退原因。面板和每轮结果保存组合、原因、耗时与可用的 Jev 元数据。
- 从 Pi 正式接口读取主会话思考强度，按注册模型的支持范围归一并展示。
- 无新第三方运行依赖。TypeSafe 密钥通过 TYPESAFE_API_KEY 读取，不保存到任务或扩展配置。

验证：71 项完整回归通过，新增选配界面测试通过；测试包含实际后台进程、取消与续任务、本地 HTTP 契约、5 个任务越过旧数量上限、真实已安装 Pi 加载器。组件预览使用模拟任务数据。真实 Jev 线上调用与中文选模效果未验证，需要本机密钥。

更新后执行 `/reload`。新增环境变量后需重启终端和 Pi。原有派遣开关保留；使用前可通过 `/agent-deck 状态` 检查。
