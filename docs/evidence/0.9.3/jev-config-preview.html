实际 TUI 组件 · 假密钥与模拟连接结果

Jev 配置，现在可以直接在 Pi 里完成

/reload → /agent-router → 填密钥 → 选模型 → 检查并保存。
这些预览调用插件实际组件生成，不是原生终端截图，也不代表个人账号已连通。

1. 打开 Jev 配置

输入 /agent-router，或从 /agent-config 进入。密钥、模型和连接状态集中显示。
