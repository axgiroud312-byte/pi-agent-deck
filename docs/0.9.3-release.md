# 0.9.3 · Jev 可视化配置

过去配置 Jev 密钥需要修改系统环境变量。现在在 Pi 输入 `/agent-router`，就能在中文菜单中完成密钥、模型、等待时间和自动选配开关的设置；`/agent-config` 也提供同一个入口。

## 使用

更新后先 `/reload`，再 `/agent-router`。从 [TypeSafe 控制台](https://console.typesafe.ai/) 获取密钥，粘贴到遮挡输入框，选择 Jev 模型，测试连接，最后保存。默认仍为 `jev-1.13.0`、15 秒；支持 `jev-latest`、`jev-preview` 和手动版本 ID。完整操作和凭据存储说明见 [README](../README.md#jev-负责模型与思考强度)。

- 测试连接通过官方模型目录接口，不提交任务；实际选配能力通过“试选一次”验证。
- 试选可选角色并输入任务，会调用 TypeSafe 推理；不创建子任务、不改变开关。
- 编辑先存为草稿，保存才生效；密钥遮挡显示、单独存入个人目录，后台进程直接读取。
- 本机密钥优先于 `TYPESAFE_API_KEY`；移除本机密钥后可回退到环境变量。
- 保留外部其他配置修改；密钥发生并发修改时拒绝覆盖。失败提示不显示原始密钥或服务端正文。
- `/agent-router on/off/status` 和非交互模式的状态查询继续可用。

0.9.2 的模型策略继续有效：审查仅用 GPT-5.6 Sol / xhigh、max；GPT-6 Sol/Luna 最低 high；Astra 的非审查档位保持原配置。主 Agent 仍决定任务数量与角色。

## 验证边界

静态检查、完整自动化测试、真实受控后台进程、隔离发布包加载与实际组件预览用于验证实现。测试使用假密钥与本地/模拟 HTTP 响应，不使用个人账号做付费推理；用户填入密钥后，连接检查和试选分别验证其实际服务情况。

[Jev 配置页组件预览](evidence/0.9.3/jev-config-preview.html)由实际 TUI 组件和模拟数据生成，不是原生 Pi 运行会话截图。
